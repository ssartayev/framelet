# Промпт для Codex

Продолжи разработку Framelet из этого репозитория. Цель — сделать редактор коротких историй, в котором пользователь выбирает сюжет из выпусков Тучного Жаба, меняет его по своему запросу и превращает результат в ролик.

Сначала открой `dist/stories.html` и `dist/stories.js`. В форме уже есть три завязки, пересказанные по выпускам Тучного Жаба, со ссылками на записи. Выбор заполняет редактируемое поле идеи. В генераторе есть выбор из трёх вступлений, отдельная перегенерация финала и экспорт. `STORY_RULES.md` автоматически добавляется к промпту для сценария и новой концовки.

Расширь подборку именно по выпускам Тучного Жаба. Для каждой записи сохраняй ссылку на выпуск и краткую завязку своими словами. Для работы с полным исходным текстом используй материалы, на адаптацию которых есть разрешение, или дай пользователю вставить свой текст. Не добавляй массовый сбор постов Reddit.

Доработай основной сценарий: выбрать историю → попросить изменить начало, финал, персонажа или дать произвольную правку → прочитать изменённый сценарий → экспортировать. При правке сохраняй согласованность персонажей и событий. Новый финал должен объяснять существующую улику, а новая версия должна быть доступна для чтения до озвучки. Повторно используй текущий генератор, правила и экспорт.

Groq работает с `GROQ_API_KEY` и используется по умолчанию при наличии ключа. В последней живой проверке оба черновика прошли проверку формата, но русский финал ушёл в посторонний сюжет, а английский финал не прошёл валидацию. Правила сюжета добавлены после этой проверки. Gemini поддерживается, но в последних запросах получил таймаут. Не меняй провайдера по умолчанию без живой проверки. Ключи берутся из окружения и не входят в репозиторий. Для тестирования Groq можно запустить `runtime/venv/bin/python scripts/compare_story_writers.py --provider groq` после настройки окружения.

Проверь, что можно выбрать завязку, получить сценарий, внести правку и затем экспортировать. Если для живой генерации или озвучки нет ключей, проверь доступную часть и укажи, какие шаги ещё не проверены.
